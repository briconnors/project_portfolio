## Personal Design Exploration: Steinway
*Reverse engineered a miniature scaled model of a Steinway baby grand piano based upon reference photos.* 

This project focused on organic structure, proportion, and stability. I designed the assembly in Onshape, and printed it using resin in the AACE lab with a Cooper material grant. The hinges were created using fishing wire, and the support provides sufficient friction to hold the lid open passively.
